# Gap Analysis

## P0 — controle e evidência

- Auditoria federada determinística.
- Schema único para estado, evidência, confiança, custo e ação.
- Saída CLI humana, JSON e non-TTY.
- Compatibilidade explícita por host e terminal.

## P1 — composição

- Projection de capability registry local.
- Separação invocação humana versus seleção agentic.
- Context pointers e handoff entre Forjas.
- Task graph proporcional a complexidade e orçamento.

## P2 — qualidade contínua

- Review independente de código, spec e contrato.
- Diagnóstico com reprodução e blast radius.
- Benchmark comparável por capability.
- Retro federada com mudança somente por decisão humana.

## P3 — experiência

- Onboarding em poucos passos com perfis econômico/completo/especialista.
- Rui/TUI resiliente em TTY, non-TTY, baixa largura, cores ausentes e terminal sem Unicode.
- Portal com status, grafo, evidência e próximos passos.
- Forja router instala adapter adequado no escopo global, projeto ou diretório.

## Non-goals

- Reescrever oito Forjas.
- Unificar storage, runtime ou linguagem.
- Criar agente central onisciente.
- Esconder gaps por fallback silencioso.
