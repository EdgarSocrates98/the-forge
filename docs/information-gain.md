# Information Gain

Information gain is a qualitative estimate of the incremental evidence a
candidate can contribute. Values are high, medium, low, none or unknown.

Inputs are explicit signals, not language-model confidence:

- remaining critical unknowns;
- other unresolved questions;
- unique candidate evidence/capability;
- verification role;
- budget/policy;
- repeated failure.

The model intentionally avoids invented percentages.
