# Quickstart — the-forge

Três comandos:

```bash
git clone <the-forge repo>
cd the-forge
./setup.sh        # Windows: .\setup.ps1
```

Depois, dentro de qualquer projeto:

```bash
cd ~/meu-projeto
theforge
```

Pronto. Abra seu AI host (Devin, Claude, Codex ou Copilot) — as skills do
the-forge já estão instaladas.

## Verificar

```bash
theforge status
theforge doctor
```
